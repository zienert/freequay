# Security

Report a vulnerability in private: open the Security tab of this repository, choose "Report a vulnerability" and describe the problem, with the Freequay version, the macOS version and the steps to repeat it. Please do not open a public issue for it.

Freequay is free and comes without support or warranty. There is no bug bounty and no promised time to answer. Only the latest release is considered.

A Windows program you start can read and change your files: Wine shows your whole Mac to it as drive Z:, and Freequay does not sandbox programs. That is not a vulnerability in Freequay. Only start programs you trust (see "Download" in the README).
